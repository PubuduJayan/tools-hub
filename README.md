# Tools Hub

✨ A free collection of simple online tools in one place:
- **Fancy Text Generator** – convert normal text into stylish Unicode fonts.
- **Word & Character Counter** – get word, char, sentence counts and reading time.
- **QR Code Creator** – generate downloadable QR codes from any text or URL.

## 📂 Project Structure
```
index.html   # Single-page app with all tools
```
No build system required – just one HTML file with embedded CSS & JS.

---

## 🛠️ Features
- ✅ Pure HTML, CSS, JS (no frameworks needed)
- ✅ Dark mode friendly UI
- ✅ Copy-to-clipboard for fancy text
- ✅ QR Code PNG download
- ✅ Mobile responsive design

---

## 🧑‍💻 Local Development
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/tools-hub.git
   cd tools-hub
   ```
2. Open `index.html` in your browser.

---

## 🌐 Deployment
### On Netlify
1. Push this repo to GitHub.
2. Go to [Netlify](https://netlify.com/).
3. New Site → Import from Git → select this repo.
4. Build settings:
   - **Build command:** *(leave empty)*
   - **Publish directory:** `/`

Netlify will deploy instantly 🚀
